About Me

I build backend systems that run where milliseconds matter, be it market data feeds, payment rails, risk engines, or order management systems. As a Backend Engineer specializing in low-latency, high-performance systems, I don't settle for code that merely works.

Whether it's a C++ feed handler parsing FIX/SBE at wire speed or a distributed pipeline extracting analytics from billions of events, I build for correctness under load. I'm passionate about distributed systems, observability, and performance profiling.
